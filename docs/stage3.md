## Step 6: reproduce one number

Target: LibriSpeech-PC test-clean, the standard check in the F5-TTS paper.

| Measure | Paper (F5-TTS Base, 32 steps) | Tool |
| --- | --- | --- |
| Word error rate | 2.42% | Whisper-large-v3 |
| Voice match (SIM-o) | 0.66 | WavLM-based speaker model |

The currently released checkpoint (`F5TTS_v1_Base`) is newer than the one in
the paper and is reported to score a little better (about 2.0% and 0.68).
Landing near either pair counts as a pass. Being far off means the setup is
wrong.

How to run it: on a machine with an NVIDIA GPU (the evaluation code only
runs on CUDA, so not the Mac):

```bash
bash scripts/run_eval.sh subset   # fixed 200 utterances, pipeline check
bash scripts/run_eval.sh full     # all 1127 utterances
```

The script wraps the commands from the evaluation guide at
`external/F5-TTS/src/f5_tts/eval/README.md` and downloads what they need
(about 7.5 GB in total, largest single file about 3.1 GB). It was run
end to end on a rented RTX 3090 on 2026-11-25.

### Result (2026-11-25)

`F5TTS_v1_Base`, 32 steps, seed 0, one RTX 3090, F5-TTS commit 600e5fd.

| Run | Word error rate | SIM-o |
| --- | --- | --- |
| Paper (older Base checkpoint) | 2.42% | 0.66 |
| Reported for `F5TTS_v1_Base` | about 2.0% | about 0.68 |
| Ours, fixed subset of 200 | 2.26% | 0.675 |
| **Ours, full test set (1127)** | **2.13%** | **0.674** |

Pass: both numbers sit between the two target pairs. One seed only, so
expect small run-to-run wobble. Per-utterance scores are in
`external/F5-TTS/results/` (not in git).

If the full test set is too slow at first, run a fixed subset of 200
utterances and note that in the log. The number will be noisier but still
shows whether the setup works.

## Known unknowns

- Answered 2026-11-25: no pretrained *small* (158M) checkpoint is published.
  The Hugging Face repo `SWivid/F5-TTS` holds only Base models. So fine-tune
  the Base model with most layers frozen instead of training small from
  scratch.
- Training from scratch is expensive: the paper reports about 8 hours on
  eight H100 GPUs per 100k steps for the small model. Plan to fine-tune.
